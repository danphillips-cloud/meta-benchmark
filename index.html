How to read this · commands · SDK docs
  • Wire is one model call, start to finish. Wall is the whole run; Wall minus Model time is local overhead.
  • Labels say their scope: run totals cover every call; last call figures describe only the final call.
  • – means the harness did not report it. It is never estimated, and no chart is drawn for it.
  • A compare run sends one prompt 2–3 ways. Its table uses medians over completed runs only; every round stays visible in the matrix.
  • Timeline middle column is time to the next step, not step cost.
